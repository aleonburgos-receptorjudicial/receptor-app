# Receptora Judicial · Curanilahue

Aplicación para organizar el trabajo diario de una receptora judicial: causas civiles y exhortos,
retiros de vehículos, boletas de honorarios y clientes (estudios jurídicos).

- Funciona en computador y celular, y se puede instalar en la pantalla de inicio.
- Todos los datos se guardan **solo en el equipo** (navegador). Este repositorio contiene únicamente
  el código de la aplicación, nunca datos de causas, personas ni boletas.

## Para desarrolladores

```bash
npm install
npm run dev      # versión de desarrollo
npm run build    # versión final en la carpeta dist/
```
